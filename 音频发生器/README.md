# 音频发生器 · Tone Generator

一个**纯前端、零依赖、完全离线**的单文件音频信号发生器：在浏览器里直接合成 1 Hz – 22 kHz 的正弦波、方波、锯齿波、脉冲波、整流波、谐波叠加和三种噪声，左右声道独立调节，并带实时示波器与电平表。适合快速检查耳机、音箱、声卡的声道与频响。

[tone-generator.html](tone-generator.html)（约 41 KB）就是全部代码，没有任何 CDN、外部音频或第三方库。

## 功能

- **频率 1 Hz – 22 000 Hz**：对数滑杆、精确数字输入、快捷预设（1 / 20 / 100 / 440 / 1 k / 5 k / 10 k / 15 k / 20 k / 22 k Hz）
- **减半 / 翻倍**：按钮和键盘 `←` / `→` 都可以，`↑` / `↓` 每次微调 ±2%
- **13 种信号**：
  - 周期波形：正弦波、三角波、上升锯齿、下降锯齿、方波、25% 脉冲、10% 脉冲、半波整流、全波整流、谐波叠加
  - 噪声：白噪声、粉红噪声、布朗噪声（全带宽，频率设置不影响输出）
- **双声道独立输出**：左右音量 0–100 各自调节，支持联动、仅左、仅右、双声道、静音和一键平衡
- **实时示波器**：直接读取输出端的 L / R 波形，按频率自适应时间窗；下方是两路 RMS 电平（dBFS）
- **持续输出**：点「开始播放」后一直发声，播放中改频率或切波形都不会中断
- **安全提示**：超过 20 kHz 提醒保护听力与高音单元；超过设备 Nyquist 频率时明确提示会混叠；次低频也会说明「听不到是正常的」

## 用法

1. 双击 `tone-generator.html`，或拖进浏览器
2. **先把左右声道音量调低**（默认 30），再点「开始播放」
3. 拖滑杆 / 输入频率 / 点预设选择频率，点波形卡片切换信号
4. 用「仅左声道」「仅右声道」检查耳机或音箱的两边是否都正常
5. 再次点「停止播放」结束输出

快捷键（焦点在输入框或滑杆内时不生效）：

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 停止 |
| `←` / `→` | 频率减半 / 翻倍 |
| `↑` / `↓` | 频率 +2% / −2% |

## 数据与状态

- 所有状态（频率、波形、音量、静音、联动）都只在当前页面的内存里，**刷新页面恢复默认**：440 Hz、正弦波、左右各 30
- 不写 localStorage / IndexedDB，不上传文件，不发任何网络请求
- 音频完全由 Web Audio 现场合成，页面不加载任何音频文件

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/tone-generator.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行：

- **初始状态**：440 Hz、正弦波、左右 30、示波器画布已创建、移动端无横向溢出
- **频率**：精确输入、对数滑杆两端、预设、减半 / 翻倍、次低频与 >20 kHz 提示
- **波形**：切换到方波 / 白噪声，校验选中态、提示文字与噪声说明
- **声道**：仅左 / 仅右 / 双声道 / 静音 / 联动 / 平衡条文字
- **播放**：桌面端给 `AudioContext` 打桩，验证开始播放会创建振荡器、切波形会重建源、切噪声会创建 BufferSource、停止后状态复位
- **快捷键**：方向键改频率、空格播放/停止，以及输入框聚焦时空格不触发播放

## 已知限制

- **必须点一次「开始播放」**：浏览器自动播放策略禁止无手势出声，页面不会自动发声
- **高频 / 大音量有风险**：长时间大音量高频可能损伤听力或高音单元，页面会提示，但请自己控制
- **超过 Nyquist 会混叠**：输出频率不能超过设备采样率的一半（常见 48 kHz 声卡是 24 kHz），超过时页面会标红提示，实际听到的不是目标频率
- **不是校准仪器**：示波器与 dBFS 表用于观察相对电平，不能替代专业声卡 / 示波器做计量
- **后台标签页可能被限速**：示波器刷新会变慢，声音由音频线程继续输出；页面重新可见时会尝试恢复被系统挂起的 AudioContext
- 不支持 IE

## 浏览器兼容

| 浏览器 | 最低版本 | 卡在哪 |
| --- | --- | --- |
| Chrome / Edge | 84 | flex `gap`（84）；`clamp()`（79） |
| Firefox | 75 | `clamp()`（75）；flex `gap`（63） |
| Safari | 14.1 | flex `gap`（14.1）；`clamp()`（13.1） |
| iOS Safari | 14.5 | 同上（iOS 14.5 的 Safari 即 14.1） |

如果只看功能、不管间距和字号，`async/await`（Chrome 55 / Firefox 52 / Safari 10.1）是下一道门槛；`:focus-visible` 和 `accent-color` 只影响焦点框和复选框颜色，要 Chrome 93 / Firefox 92 / Safari 15.4 才完全一致。

Firefox 未纳入 CI 测试矩阵，版本按特性支持情况推算；低于表中版本时页面可能仍能打开，但会出现排版错位或个别功能不可用。不支持 IE。
