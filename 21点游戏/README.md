# 21 点游戏 · Blackjack

两个版本的 21 点（Blackjack），都是纯前端单文件页面，双击即可在浏览器中打开，无需构建、无需联网、不依赖任何第三方库。

| 版本 | 文件 | 定位 |
| --- | --- | --- |
| 普通版（摸鱼版） | [21.html](21.html) | 伪装成「学术能力测试系统」，适合在工位低调地玩 |
| Plus 版 | [21plus.html](21plus.html) | 赌场绿桌布风格的全特效原版 21 点 |

## 普通版：21.html（摸鱼版）

整个页面伪装成一套平平无奇的「学术能力测试 (Academic Test)」，浏览器标签页标题是「学习版测试系统」。黑白等宽字体、纯文字卡牌，混在一堆工作文档里也不显眼。

- 界面术语全部是「学生 / 老师」「学分」「开始测试 / 继续答题 / 结束答题」，看不出是在打牌
- 卡牌花色用「甲、乙、丙、丁」代替 ♠♥♣♦，牌面是纯文字，例如 `[10甲]`；庄家第一张牌显示为 `[??]`
- 底纹背景可自定义：页面读取同目录下的 `bg.jpg`，用 `background-size: cover` 铺满全屏。把 `bg.jpg` 换成任意图片（保持文件名不变）即可，建议用不显眼的图
- **注意：仓库里的 `bg.jpg` 目前是 0 字节的空文件**，替换成真实图片后背景才会生效

## Plus 版：21plus.html（全特效版）

原版 21 点，赌场绿桌布风格，视觉和动效都更完整。

- 标准扑克牌：四色花色 ♠♥♣♦，纯 CSS 绘制的牌面，带发牌动画
- 大字比分、下注区、余额显示，布局随屏幕自适应（桌面 / 手机均可）
- 按钮是「要牌 (Hit)」「停牌 (Stand)」，节奏更接近真实 21 点

## 规则

- 单副 52 张牌，**每局重新洗牌**；庄家与玩家各发两张，庄家第一张扣着
- 目标是让手牌尽量接近 21 点又不超过，超过 21 点立即爆牌，本局结束
- A 可算 1 或 11（自动取最有利的算法），J / Q / K 算 10
- 起手就是 21 点时自动停牌结算，不用自己点
- 庄家点数 **小于 17 必须继续要牌**，17 点及以上停牌
- 结算：庄家爆牌或玩家点数更大 → 赢，返还双倍下注（净赚一份）；点数相同 → 平局，退回本金；玩家点数更小 → 输掉下注
- 初始 1000 学分 / 余额，每局可自己填下注额（1–1000，默认 10）；下注超过余额会被拒绝
- 没有分牌、加倍、保险这些进阶玩法

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/21-dian.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行。为了结果可复现，测试会替换页面里的牌堆，构造出确定的牌局：

- 普通版：伪装文案与标题、`bg.jpg` 背景是否真的加载、A 的 1/11 计分、完整走一局（投入学分 → 要牌 → 停牌 → 结算）、下注为 0 时提示且不发牌
- Plus 版：初始按钮状态、A 的 1/11 计分、完整一局结算、下注为 0 的校验
- 边界：起手 21 点自动结算、要牌爆牌、与庄家同点平局退本金、庄家爆牌玩家获胜、庄家点数更高判负、下注超过余额拒绝开局、一局结束后可以接着再来一局且余额累计
- 移动端：窄屏无横向溢出、可触控开始

## 已知限制（如实说明）

- 牌局状态只在内存里，**刷新页面余额就回到 1000**
- 普通版依赖同目录的 `bg.jpg`，只移动 `.html` 文件不会带上背景（但没有背景图也能正常玩）
- 两个版本都不含分牌、加倍、保险，也不统计历史战绩

## 浏览器兼容

两个版本的门槛差得比较多：

| 版本 | Chrome / Edge | Firefox | Safari | iOS Safari | 卡在哪 |
| --- | --- | --- | --- | --- | --- |
| 普通版 `21.html` | 49 | 44 | 10 | 10 | `const/let`（49 / 44 / 10）、模板字符串（41 / 34 / 9.1） |
| Plus 版 `21plus.html` | 84 | 63 | 14.1 | 14.5 | flex `gap`（Chrome 84 / Firefox 63 / Safari 14.1）、CSS 变量（49 / 31 / 9.1） |

Firefox 未纳入 CI 测试矩阵，版本按特性支持情况推算；低于表中版本时页面可能仍能打开，但会出现排版错位或个别功能不可用。不支持 IE。
