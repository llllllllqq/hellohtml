# 21 点游戏

两个版本的 21 点（Blackjack），都是纯前端单文件页面，双击即可在浏览器中打开，无需构建或联网。

| 版本 | 文件 | 定位 |
| --- | --- | --- |
| 普通版 | [21.html](21.html) | 伪装成「学术能力测试系统」，适合隐蔽摸鱼 |
| Plus 版 | [21plus.html](21plus.html) | 全扑克牌特效的原版 21 点 |

## 普通版：21.html（摸鱼版）

整个页面伪装成一套平平无奇的「学术能力测试 (Academic Test)」，浏览器标签页标题为「学习版测试系统」。黑白等宽字体、纯文字卡牌，混在一堆工作文档里也不显眼。

- 界面术语全部是「学生 / 老师」「学分」「开始测试 / 继续答题 / 结束答题」，看不出是在打牌
- 卡牌花色用「甲、乙、丙、丁」代替 ♠♥♣♦，牌面纯文字显示（如 `[10甲]`）
- 背景图可自定义：页面会读取同目录下的 `bg.jpg`，用 `background-size: cover` 铺满全屏。把 `bg.jpg` 换成任意图片（保持文件名不变）即可。**注意：当前仓库里的 `bg.jpg` 是 0 字节空文件，替换成真实图片后背景才会生效**。建议用不显眼的图片，摸鱼更隐蔽

## Plus 版：21plus.html（全特效版）

原版 21 点，赌场绿桌布风格，视觉和动效都更完整。

- 标准扑克牌：四色花色 ♠♥♣♦，纯 CSS 绘制的牌面，带发牌动画
- 大字比分、下注区、余额显示，布局随屏幕自适应（桌面 / 手机均可）
- 按钮为「要牌 (Hit)」「停牌 (Stand)」，游戏节奏更接近真实 21 点

## 玩法规则

- 目标是让手牌点数尽量接近 21 点且不超过，超过 21 点即爆牌
- A 可算 1 或 11，J / Q / K 算 10
- 初始 1000 学分，每局可自行输入下注额；赢一局返还双倍下注（含本金），平局退回本金
- 庄家点数在 17 点以下必须继续要牌
- 普通版用「继续答题 / 结束答题」代替要牌 / 停牌，Plus 版直接使用「要牌 / 停牌」
