# 提醒器 · Reminder

一个**零依赖、纯前端、完全离线**的单文件提醒工具：双击打开就能按天 / 按周 / 按月 / 一次性定时提醒，数据存在本机浏览器里，不上传、不联网。

[reminder.html](reminder.html)（约 53 KB）就是全部代码，没有任何 CDN 或第三方库。

## 功能

- **四种重复方式**：每天、每周（可多选星期几）、每月（几号，遇到没有这天的月份自动落到月末）、一次性（指定日期）
- **到点弹层提醒**：全屏弹层显示提醒内容和原定时间，可「我知道了」或「稍后再说」（默认 5 分钟后）
- **稍后标记**：点「稍后再说」后，列表里这条提醒会挂上「稍后 09:05」的小标签，「下一个」也会优先显示它；到点再响后标记自动消失
- **标签页图标提醒**：有提醒弹出时，标签页图标右上角出现红点，确认后恢复成普通图标；浏览器在后台时，标签栏和任务栏缩略图上也能一眼看到
- **声音提醒**：内置三声上行提示音（每 2.6 秒一次）；也可以填同目录下的音频文件名，用自己的声音。响多久由设置里的「响铃最长时长」决定
- **标题闪烁 + 系统通知**：标签页标题交替闪烁 `● 提醒内容`；用 http(s) 打开并授权后，还会发一条桌面通知
- **错过补提醒**：页面打开时会检查最近 60 分钟内错过的提醒并补弹一次，同时如实标注「几分钟前已到点」
- **睡眠 / 冻结检测**：页面被系统挂起、标签页被浏览器冻结或从后台恢复时，会立即重新校准计时；挂起期间到点的提醒马上补弹，并标注「页面被挂起约 X 分钟」，超出补提醒窗口的会明确提示已跳过
- **多标签页不重复响**：同一浏览器里只有一个标签页负责响铃，其余页面顶部提示「另一个标签页正在负责提醒」，可一键接管；接管后原页面会立刻停手，正在响的提醒也会收起
- **设置面板**：默认音量、提示音开关、响铃最长时长、稍后再说间隔、错过补提醒窗口，改完立即生效
- **备份与迁移**：一键导出 `config.txt`（含设置），换电脑/换浏览器时导入即可

## 数据存在哪

提醒内容默认存在浏览器的 IndexedDB（库名 `reminder_app`），因此**不需要任何配置文件**也能正常使用；数据库不可用时自动降级到 localStorage（容量较小，页脚会标注「已存入本地存储（降级）」）。

`config.txt` 只是备份文件：

- 导出：点页脚「导出备份」，得到 `config.txt`（内容是一段 `window.REMINDERS = {...};`）
- 导入：点页脚「从备份导入」选择该文件，会**覆盖**当前列表
- 也可以在页面同目录放一个 `config.txt`，首次打开且数据库为空时自动读取一次，之后以数据库里的内容为准

`config.txt` 里的内容不会自动同步，改完记得再导出一次；页脚出现「未备份」表示有改动还没导出。

## 用法

1. 双击打开 `reminder.html`
2. **先点一下顶部状态条**（浏览器要求用户操作后才允许出声，这步必须做）
3. 点「+ 添加提醒」，填内容、选重复方式、选时间，保存
4. 页面保持打开（可以缩到后台），到点就会弹出来

提示音文件放在与本页面同一目录，然后在「提示音文件」里填相对路径，例如 `ding.mp3` 或 `sounds/ding.wav`（支持 mp3 / wav / ogg / m4a）。文件找不到时会自动降级为内置提示音，并在列表里标注「音频 xxx 缺失」。

按 `Esc` 可关闭编辑对话框。

## 设置

点页脚右下角的「⚙ 设置」：

| 设置项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 默认音量 | 80% | 0–100% | 拖动即时生效，松手试听一声；0% 等于静音 |
| 提示音 | 开 | 开 / 关 | 关掉后到点只弹层、不发声 |
| 响铃最长时长 | 120 秒 | 5–600 秒 | 到点自动静音，弹层保留；提示音文件比它长时只播前这么多秒，比它短则循环播放 |
| 稍后再说 | 5 分钟 | 1–60 分钟 | 「稍后再说」按钮的间隔 |
| 错过补提醒 | 60 分钟 | 0–180 分钟 | 重新打开页面时补提醒的时间窗，0 表示不补 |

设置和提醒一起存在浏览器数据库里；导出备份时会写进 `config.txt` 的 `settings` 字段，导入时一并恢复。改动没导出前，页脚会显示「未备份」。

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/reminder.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行：

- **规则引擎**：每天 / 每周（工作日、周末、任意组合）/ 每月（含 2 月没有 31 号时收敛到月末）/ 一次性的「下次时间」与文字描述
- **到点触发**：用 Playwright 假时钟把时间推到触发点，验证弹层内容、原定时间、「我知道了」与「稍后再说」（按设置里的分钟数再次弹出）
- **错过补提醒**：把系统时间推到 5 分钟后重新载入页面，验证补弹与「页面刚打开」标注
- **睡眠 / 冻结**：派发 `freeze` / `resume` 并把系统时间推进 5 分钟，验证恢复后补弹、标注「页面被挂起约 5 分钟」；没有到期提醒时只提示已重新校准
- **数据**：新建 / 编辑 / 暂停 / 删除（含确认框）、刷新后仍在（IndexedDB）、导出 `config.txt` 后重新导入、损坏备份文件报错
- **标签图标**：提醒弹出时 favicon 变成带红点的版本，确认后恢复成原图
- **稍后标记**：点「稍后再说」后列表出现「稍后 hh:mm」标签、「下一个」变成稍后提醒，到点再响后标记消失
- **设置**：面板回显、改音量 / 稍后再说后刷新仍在、音量 0 显示「静音」、关掉提示音后仍然弹层、补提醒窗口设 0 后不再补弹、响铃到设定时长后确认不再发声（数合成音产生的振荡器）、导出的备份里带上设置
- **多标签页**：第二个标签页不响铃并可接管；接管后原页面不再响铃、正在响的提醒会被收起（两条回归用例）
- **移动端**：窄屏编辑器与列表不横向溢出、提醒弹层按钮可点

## 已知限制（如实说明）

- **页面必须开着**：纯前端页面没有 Service Worker / 后台进程，浏览器关掉或电脑休眠期间不会响；恢复后会自动检测挂起时长，补「错过补提醒」窗口内的提醒（默认 60 分钟，可在设置里调成 0 关闭），超出窗口的会提示已跳过
- **后台标签页会被限速**：Chrome 等浏览器会把后台定时器降到约 1 分钟一次，提醒可能晚几十秒；页面重新可见时会立刻补检查一次
- **只在本机本浏览器生效**：数据不跨设备同步，换设备请用备份文件迁移
- **必须点一次页面**：浏览器自动播放策略禁止无交互出声，未点击时状态条会提示「声音未启用」
- 系统通知仅支持 http(s)（`file://` 打开时没有通知，只有弹层和标题闪烁）
- 提醒时间按设备本地时区解释，跨时区旅行/改系统时间后，已经算好的「下次」会按新时间重算
- 同时打开多个标签页时只有一个负责响铃，其它页不会重复提醒
- 「稍后再说」和它的标记只存在于当前页面的内存里，刷新页面就没了（提醒本身不受影响）；手动接管时它也不会搬到新页面
- 用浏览器的「复制标签页」打开同一页面时，两个标签页可能拿到相同的 `window.name`（页面靠它区分标签页），这种情况下会退化成两个都响
- 响铃到「响铃最长时长」后只是不再发声，弹层和标题闪烁会一直保留，直到你点「我知道了」

## 浏览器兼容

| 浏览器 | 最低版本 | 卡在哪 |
| --- | --- | --- |
| Chrome / Edge | 55 | `async/await`（55） |
| Firefox | 52 | `async/await`（52） |
| Safari | 10.1 | `async/await`（10.1） |
| iOS Safari | 10.3 | 同上 |

页面本身很朴素：IndexedDB、WebAudio、`Element.closest`（Safari 9.1）都远低于上表门槛，真正卡住下限的只是 `async/await`。

睡眠 / 冻结检测优先用 Page Lifecycle 的 `freeze` / `resume`（Chrome 支持），其它浏览器靠 `visibilitychange` 和定时器间隔兜底，不会抬高上面的版本门槛。

Firefox 未纳入 CI 测试矩阵，版本按特性支持情况推算；低于表中版本时页面可能仍能打开，但会出现排版错位或个别功能不可用。不支持 IE。
