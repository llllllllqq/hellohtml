# 生日老虎机 · Happy Slot

一台只用 HTML/CSS/JS 做的生日老虎机：拉下魔法拉杆，看看今天你「被」谁怎么样。攒满幸运值还会掉彩蛋——「被」会悄悄变成「把」，句子就通啦。

[birthday-slot-machine.html](birthday-slot-machine.html)（约 32 KB）就是全部代码，音效全部用 WebAudio 现场合成，不含任何外部资源。

## 玩法

1. 双击打开页面，先输入昵称（最多 8 个字，默认「小明」），点「开始许愿 ✨」
2. 点拉杆或「🎰 拉一次」：两个卷轴错开滚动，最后停在「名词 + 动词」的组合上
3. 结果拼成一句话：**「昵称」被「🎂 蛋糕」吃了** —— 名词 6 种、动词 6 种，共 36 种组合
4. 想改名：点左侧名字卷轴或「✏️ 改昵称」，改完当前这局的句子会立刻用新名字重绘

**彩蛋**：抽到「蛋糕 + 吃」时，「被」字会先变形再变成「把」——「昵称」把「蛋糕」吃了！同时弹出贺卡、满屏「生日快乐」字样和 60 片彩带，4.2 秒后自动收起。

**保底**：底部幸运值每拉一次涨一格（`0 / 10`），第 10 拉强制出彩蛋，不会一直空手。

**隐藏小彩蛋**：三个特定组合会在结果下方冒一句吐槽（不弹窗、不打断），例如「猫猫 + 投喂」「仓鼠 + 施魔法」「猫猫 + 绑架」。

## 界面上还有什么

- 拉动次数、彩蛋触发次数实时累计，「🔄 重置记录」一键清零
- 右上角 🔊 / 🔇 切换音效（拉杆声、滚动滴答声、中奖音、彩带都没有外部音频文件）
- 昵称越长字号越小（2 / 4 / 6 / 8 字四档），名字再长也不会撑破卷轴
- 背景是随机点缀的星星、糖果，卷轴窗口尺寸变化时会重新对齐，不会错位

## 实现细节

- 卷轴把词库重复 7 份拼成一条长带，靠 `transform: translateY()` 滚动，停稳后瞬间归位到等价位置，视觉无缝
- 两个卷轴分别滚 2.4 s / 2.7 s，制造真实老虎机的错落感；滚动时每 90 ms 一声滴答
- 「被 → 把」分三段：430 ms 变形、780 ms「了」弹一下、1250 ms 收尾，之后才改写整句
- 全部状态都在内存里，**刷新页面记录就清零**

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/birthday-slot.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行：

- 首屏弹出昵称对话框，默认昵称「小明」
- 设置昵称后弹层关闭、昵称写入卷轴
- 固定随机数后拉一次：拉动次数 +1、生成的句子包含昵称与词库里的名词、幸运值变成 `1 / 10`
- 把随机数固定成彩蛋组合：彩蛋计数 +1、「被」变成「把」、贺卡出现并在 4.2 秒后自动收起
- 「重置记录」把拉动次数与彩蛋数清零
- viewport 声明与横向溢出检查

## 已知限制（如实说明）

- 纯前端玩具，**没有存档**：刷新或关掉页面，昵称、次数、彩蛋数都会重置
- 彩带用 `Element.animate()` 实现，非常老的浏览器上会不动，但不影响出结果

## 浏览器兼容

| 浏览器 | 最低版本 | 卡在哪 |
| --- | --- | --- |
| Chrome / Edge | 87 | 遮罩与背景层用的 `inset:0`（87）、flex `gap`（84） |
| Firefox | 75 | `clamp()` / `min()`（75） |
| Safari | 14.1 | `inset:0` 与 flex `gap`（14.1） |
| iOS Safari | 14.5 | 同上 |

昵称弹窗的毛玻璃（`backdrop-filter`）只影响观感：Firefox 103 以下、Safari 18 以下会退化成普通半透明底，不影响使用。

Firefox 未纳入 CI 测试矩阵，版本按特性支持情况推算；低于表中版本时页面可能仍能打开，但会出现排版错位或个别功能不可用。不支持 IE。
