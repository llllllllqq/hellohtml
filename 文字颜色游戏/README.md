# 文字颜色游戏 · 读色挑战（白底版）

一个斯特鲁普效应（Stroop）小游戏：屏幕上出现一个**颜色词**，但这个词是用另一种颜色写的，你要说出「字的颜色」而不是「字的意思」。

[stroop-white.html](stroop-white.html)（约 8 KB）就是全部代码，白底大字、零依赖。

## 玩法

1. 双击打开页面，先认一下这 7 种颜色（色卡由游戏里的同一份颜色表生成，看到什么就是游戏里显示的什么）
2. 点击屏幕任意处（或按 `空格` / `回车`）开始
3. 每点一下换一题，题目的「字义」和「字色」都是随机的，并且都**不会与上一题重复**
4. 玩法可以自己加难度：只说颜色、只说字、或者两个字同时说

## 7 种颜色

| 颜色 | 字芯色值 | 描边 | 说明 |
| --- | --- | --- | --- |
| 红色 | `#DE2910` | 无 | 国旗红，白底上足够清楚 |
| 黄色 | `#F0DC00` | `#7A6600` | 亮黄在白底上发虚，加一圈深黄描边 |
| 绿色 | `#16A34A` | 无 | |
| 蓝色 | `#2563EB` | 无 | |
| 粉色 | `#FF9EC7` | `#C2185B` | 亮粉 + 深玫红描边 |
| 黑色 | `#111111` | 无 | |
| 白色 | `#FFFFFF` | `#111111` | 白字靠黑色描边勾出字形 |

文字用 `-webkit-text-stroke` + `paint-order: stroke fill` 描边，字号随屏幕宽度自适应（`clamp`），横竖屏都不会溢出。

## 实现细节

- 颜色、描边、描边宽度都定义在同一个 `COLORS` 数组里，开场色卡由它生成，所以色卡和题目永远一致
- 出题时颜色、字义分别独立随机，并排除上一题的下标，避免连续两题完全相同
- 120 ms 防连点锁；每次出题重播一次 pop 动画
- 不支持 Pointer Events 的老浏览器自动退回 `touchstart`

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/stroop.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行：

- 开场有且只有 7 个色卡，`#word` 还是空的
- 点击开始后连续出 4 题：每题的「文字」和「实际颜色」都在 7 种之内，且与上一题都不同
- 每次出题都带上 pop 动画类
- viewport 声明与横向溢出检查

## 浏览器兼容

| 浏览器 | 最低版本 | 卡在哪 |
| --- | --- | --- |
| Chrome / Edge | 87 | 开场遮罩的 `inset:0`（87）、flex `gap`（84）、`clamp()`（79） |
| Firefox | 75 | `clamp()`（75） |
| Safari | 14.1 | `inset:0` 与 flex `gap`（14.1） |
| iOS Safari | 14.5 | 同上 |

`-webkit-text-stroke` 本身很老（Safari 3+、Firefox 49+、Chromium 一直支持），不是门槛。

Firefox 未纳入 CI 测试矩阵，版本按特性支持情况推算；低于表中版本时页面可能仍能打开，但会出现排版错位或个别功能不可用。不支持 IE。
