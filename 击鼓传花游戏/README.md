# 击鼓传花 · Drum & Flower

一个纯前端单文件小游戏：点一下开始击鼓，鼓声在 3–10 秒之间**随机**停止，整屏变红的那一刻，正拿着花的人就输啦。

[drum-flower.html](drum-flower.html)（约 9 KB）就是全部代码，不发网络请求、不依赖任何外部音频或图片。

## 玩法

1. 双击打开 `drum-flower.html`（手机也可以直接打开）
2. 点击屏幕任意处开始，或按 `空格` / `回车`：大号「咚」字随鼓点跳动，提示行变成「传花中… 鼓声随时会停」
3. 鼓声随机停止时，整屏变成国旗红，大字变成「停！」，支持震动的设备会震一下
4. 再点任意处开始下一轮；鼓声响起期间点击会被忽略（什么时候停只由鼓声决定）

右上角常驻「鼓声 开 / 鼓声 关」按钮，点击它只切换声音，**不会**误触发开始。

## 实现细节

- **鼓声现场合成**，零音频文件：低频正弦从 190 Hz 快速滑到 55 Hz 当作「咚」，再叠一段 70 ms 的衰减白噪声当作鼓皮
- 节拍每 480 ms 一击；停止时间取 `3000 + Math.random() * 7000`（3–10 秒）
- 结束态靠 CSS 变量 `--red: #DE2910` 全屏变红，「停！」带 pop 动画
- 120 ms 防连点锁；不支持 Pointer Events 的老浏览器自动退回 `touchstart`

## 测试

测试在仓库根目录的 Playwright 套件里（`tests/drum-flower.spec.js`），随 CI 在三种环境（桌面 Chrome / Pixel 5 / iPhone 13）运行：

- 初始界面文案、`#intro` 可见、鼓声开关默认「鼓声 开」
- 点鼓声按钮只切换开关，不会误触发开始
- 用假时钟把时间推进 10.5 秒：进入结束态、背景变红、大字变「停！」，再点可以重开
- viewport 声明与横向溢出检查

## 浏览器兼容

Chrome / Edge 74+、Firefox 75+、Safari 13.1+、iOS Safari 13.4+（依赖 WebAudio 与 Pointer Events）。不支持 IE。
